# Frontend Capstone Project — Group 15 (Phoenix Cohort)

A React web application that explores our solar system through data. Built as a capstone project for the TS Academy Frontend Development course.

---

## 🔗 Live Demo

| **Deployment Link** |https://capstone-project-grp15.netlify.app/ |

---

## 📋 Project Summary

This application recreates a provided Figma mockup as a fully working React web app. It fetches real planet data from an external NASA API and displays it in a responsive grid of planet cards. It also includes a comparative NASA data table and a validated contact form. The project demonstrates HTML, CSS and JavaScript fundamentals, React component architecture, the Fetch API, responsive design, and collaborative Git workflows — all skills covered throughout the TS Academy Frontend Development course.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed on your machine:

- [Node.js](https://nodejs.org/) (v18 or higher)
- [Git](https://git-scm.com/)

### Installation

1. **Clone the repository**

```bash
   git clone https://github.com/Erijesu0/Group-15-Capstone-project-phoenix.git
```

2. **Navigate into the project folder**

```bash
   cd Group-15-Capstone-project-phoenix
```

3. **Install dependencies**

```bash
   npm install
```

4. **Start the development server**

```bash
   npm run dev
```

5. Open your browser and visit `the local host displyed in the terminal`

## 🔀 Git Workflow

1. All work is done on **separate branches** — never directly on `main`
2. Contributions are submitted through **Pull Requests (PRs)**
3. The person who opens a PR **must not** review or merge their own PR
4. PRs must be **reviewed and approved** before being merged into `main`
5. Use the **GitHub Projects** board to manage and track tasks
